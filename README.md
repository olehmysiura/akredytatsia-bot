# Бот «Підготовка до акредитації» — розгортання на Vercel

Ця версія бота працює на Vercel без власного сервера і без комп'ютера, який треба тримати увімкненим. Telegram сам надсилає кожне повідомлення на адресу вашого проєкту (webhook), а прогрес тестів і результати студентів зберігаються в безкоштовній базі **Upstash Redis**, яка підключається прямо у Vercel.

Знадобиться: акаунт Telegram, акаунт **GitHub** (безкоштовний) і акаунт **Vercel** (можна зареєструватися через GitHub). Усе робиться в браузері, без встановлення програм. Займає ~20 хвилин.

---

## Крок 1. Створіть бота в Telegram

1. Відкрийте **@BotFather** → `/newbot`.
2. Вкажіть назву і username, що закінчується на `bot`.
3. Збережіть **токен** вигляду `1234567890:AA...` — він знадобиться в кроці 5.

## Крок 2. Завантажте файли на GitHub

1. Увійдіть на github.com → **New repository** (кнопка «+» вгорі праворуч).
2. Назва, наприклад, `akredytatsia-bot`. Можна обрати **Private**. Натисніть **Create repository**.
3. На сторінці репозиторію натисніть **uploading an existing file** (або **Add file → Upload files**).
4. Перетягніть **усі файли з цієї папки** (не саму папку): `app.py`, `core.py`, `quiz.py`, `questions.json`, `requirements.txt`, `README.md`.
5. Натисніть **Commit changes**.

## Крок 3. Створіть проєкт у Vercel

1. Увійдіть на vercel.com (кнопка **Continue with GitHub**).
2. **Add New… → Project** → знайдіть репозиторій `akredytatsia-bot` → **Import**.
3. Нічого не змінюйте — Vercel сам розпізнає Python/Flask. Натисніть **Deploy**.
4. Після деплою ви побачите адресу проєкту, наприклад `https://akredytatsia-bot.vercel.app`. Запишіть її.

## Крок 4. Підключіть базу даних Upstash Redis

1. У проєкті Vercel відкрийте вкладку **Storage**.
2. **Create Database** (або **Browse Marketplace**) → оберіть **Upstash** → **Upstash for Redis**.
3. Оберіть безкоштовний план (**Free**), регіон ближче до Європи (наприклад, Frankfurt) → **Create**.
4. Підключіть базу до проєкту (**Connect Project**). Vercel сам додасть змінні `KV_REST_API_URL` і `KV_REST_API_TOKEN`.

## Крок 5. Додайте налаштування бота

У проєкті: **Settings → Environment Variables**. Додайте:

| Назва | Значення |
|---|---|
| `BOT_TOKEN` | токен від @BotFather |
| `WEBHOOK_SECRET` | придумайте довгий пароль лише з латинських букв, цифр, `_` або `-`, напр. `kuep_akred_2026_x7Qp9` |
| `ADMIN_IDS` | Telegram ID викладачів через кому (можна заповнити пізніше, див. крок 8) |

Після цього: вкладка **Deployments** → у останнього деплою меню **⋯** → **Redeploy**. Без повторного деплою нові змінні не застосуються.

## Крок 6. Перевірте, що все підключено

Відкрийте в браузері адресу проєкту, наприклад `https://akredytatsia-bot.vercel.app/`. Має з'явитися:

```
{"database_connected": true, "questions": 93, "secret_set": true, "status": "ok", "token_set": true}
```

Якщо десь `false` — поверніться до кроку 4 або 5 і не забудьте **Redeploy**.

## Крок 7. Підключіть бота до Telegram (один раз)

Відкрийте в браузері (підставте свою адресу і свій `WEBHOOK_SECRET`):

```
https://akredytatsia-bot.vercel.app/setup?key=kuep_akred_2026_x7Qp9
```

Має з'явитися «✅ Готово! Webhook … встановлено». Тепер відкрийте бота в Telegram і натисніть **Start** — він працює цілодобово.

## Крок 8. Доступ викладачів до результатів

1. Напишіть боту `/myid` — він надішле ваш Telegram ID.
2. Впишіть його в змінну `ADMIN_IDS` (кілька ID — через кому) і зробіть **Redeploy**.
3. Команда `/report` надсилатиме файл з результатами всіх студентів (відкривається в Excel).

## Як змінити питання

Відредагуйте `questions.json` прямо на GitHub (відкрийте файл → іконка олівця → **Commit changes**). Vercel автоматично перерозгорне бота за хвилину. Формат питання:

```json
{
  "block": 1,
  "ref": "№ 22",
  "q": "Скільки годин становить один кредит ЄКТС?",
  "correct": "30 годин",
  "wrong": ["36 годин", "45 годин", "20 годин"],
  "explain": "Обсяг одного кредиту ЄКТС становить 30 годин..."
}
```

Рівно три неправильні варіанти; порядок не важливий — бот перемішує сам. Стежте, щоб правильна відповідь не була помітно довшою за інші.

## Якщо щось не працює

- **Бот мовчить.** Повторіть крок 7. У Vercel: **Logs** — там видно помилки.
- **У логах 401 / 403 на `/webhook`.** У **Settings → Deployment Protection** переконайтеся, що захист не ввімкнено для основного (Production) домену — Telegram має мати доступ до адреси без входу. 403 також буває, якщо змінили `WEBHOOK_SECRET` і не повторили крок 7.
- **Після зміни змінних нічого не змінилося.** Потрібен **Redeploy**.
- **Змінили токен бота** (наприклад, через `/revoke`) — оновіть `BOT_TOKEN`, зробіть Redeploy і повторіть крок 7.

## Тарифи

Безкоштовний тариф Vercel (Hobby) призначений для особистого некомерційного використання; для проєкту закладу освіти перегляньте актуальні умови Vercel. Безкоштовного плану Upstash Redis для бота однієї-кількох груп має вистачати з запасом.
